<h3 align="center">🧠 Fault-Tolerant Distributed ML</h3>

A synchronous data-parallel training system that combines a NumPy neural network with custom Ring-AllReduce over gRPC.

- Coordinates training steps and gradient synchronization across workers.
- Uses checkpoint rollback and coordinated recovery after worker failures.
- Tests fault handling with Docker-based experiments on digits and CIFAR-10 workloads.

`Python` `NumPy` `gRPC` `Docker` `Ring-AllReduce`

<h3 align="center">🏦 Distributed Banking Simulation</h3>

A Go-based banking simulation exploring replicated state and transaction coordination across shards.

- Uses Paxos for consensus within clusters.
- Coordinates cross-shard transactions with two-phase commit.
- Includes SQLite persistence, RPC communication, and performance reporting.

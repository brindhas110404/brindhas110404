## 👩‍💻 About Me

My projects explore **distributed systems and machine learning infrastructure**: how workers coordinate, how replicas agree, and how a system recovers when something fails.

I work with **Python, Go, gRPC, and Docker**, with a focus on understanding the mechanisms behind distributed computation—from gradient synchronization to cross-shard transactions.

<h3>🧠 Fault-Tolerant Distributed ML</h3>

A synchronous data-parallel training system combining a NumPy neural network with custom Ring-AllReduce over gRPC.

- Coordinator-controlled training steps and gradient synchronization.
- Checkpoint rollback and coordinated worker recovery.
- Docker-based experiments with digits and CIFAR-10 workloads.
- Fault-injection validation against serial SGD.

`Python` `NumPy` `gRPC` `Docker` `Ring-AllReduce`
